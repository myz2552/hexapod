# CAD

Bu klasör yalnızca TouchSight Hexapod için oluşturulan veya değiştirilen CAD dosyalarını içerir.

- Mekanik referans: [ggldnl/Hexapod-Hardware](https://github.com/ggldnl/Hexapod-Hardware)
- Kullanılan ve değiştirilecek parçalar: [docs/cad-reference.md](../docs/cad-reference.md)

Upstream STL/STEP dosyaları bu repoya kopyalanmaz. Lisans/izin durumu teyit edilmeden upstream'den türetilmiş CAD dosyaları kamuya açık şekilde paylaşılmamalıdır.

```text
cad/
├── modified/   Projeye göre yeniden tasarlanan parçalar (Pi 5 yuvası, PCA9685 montajı, kamera yuvası, güç yerleşimi, ön tampon)
└── README.md
```
